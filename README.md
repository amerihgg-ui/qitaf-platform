# قِطاف V19 — إعادة بناء نظيفة

هذه النسخة مستقلة عن تراكمات V8–V18، وتستخدم `index.html` وملفي `assets/app.css` و`assets/app.js` فقط.

## التشغيل

1. شغّل `supabase-setup.sql` كاملًا في Supabase SQL Editor.
2. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub Pages.
3. انتظر نجاح GitHub Actions ثم افتح الموقع واضغط `Ctrl + F5`.

## الواجهات

- العميل: `index.html`
- الإدارة: `index.html#admin`
- المندوب: `index.html#driver`
- من نحن: `about.html`

تسجيل الدخول والصلاحيات مؤجل كما طلبت، لذلك واجهتا الإدارة والمندوب مفتوحتان مؤقتًا للمراجعة.
