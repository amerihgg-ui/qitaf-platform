# قِطاف V9 — النظام المترابط

نسخة مترابطة تشمل الطلبات والتسليم والمخزون وفواتير البيع والموردين والمشتريات والمصروفات والحسابات والمندوبين ورفع صور المنتجات.

## تجهيز Supabase (مرة واحدة)

1. افتح مشروع Supabase ثم SQL Editor.
2. افتح ملف `supabase-setup.sql` من هذه النسخة.
3. انسخ محتواه كاملًا، اضغط Run، وتأكد من ظهور Success. شغّله مجددًا حتى لو شغّلت ملف V8 سابقًا، لأنه يضيف جداول الحسابات الجديدة.

## النشر

1. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub.
2. افتح Settings ثم Pages.
3. من Source اختر GitHub Actions.
4. افتح Actions وانتظر اكتمال عملية Deploy Qitaf to GitHub Pages.

رابط الموقع:
`https://amerihgg-ui.github.io/qitaf-platform/`

## اختبار الربط

1. من الإدارة أضف قسمًا ومنطقة توصيل ومنتجًا بصورة.
2. من واجهة العميل نفّذ طلبًا.
3. افتح صفحة المندوب؛ سيظهر الطلب نفسه ويمكن تسجيل تسليمه.
4. غيّر الحالة من الإدارة وافتح حساب العميل لمشاهدتها.

## قواعد الحسابات

- التسليم ينقص المخزون وينشئ فاتورة وحركة بيع مرة واحدة.
- صافي الربح = المبيعات المسلّمة - تكلفة البضاعة المباعة - المصروفات.
- شراء المخزون لا يُعتبر مصروفًا تشغيليًا؛ المدفوع ينقص الخزنة والباقي يظهر دين مورد.
- رأس المال يزيد الخزنة ولا يُحسب ضمن الأرباح.

ملاحظة: سياسات قاعدة البيانات في هذه النسخة مفتوحة مؤقتًا للاختبار. يجب إضافة تسجيل الدخول والصلاحيات قبل التشغيل التجاري.
